# FEM-LLM-web

지오메트리를 웹에 올리고, 문장으로 경계조건·하중을 지시한 뒤, 로컬 솔버로 해석하고 결과를 3D로 확인하는 개인용 FEM 도구입니다.

```
지오메트리 업로드 (OBJ / STL)
  → 문장 지시 → LLM이 스펙 수정 지시(JSON)를 생성 → 검증 → 화면에 구속·하중 표시
  → 해석 실행 (로컬 솔버)
  → 변형·컨투어·그래프 확인 (그래프도 문장으로 요청)
```

| 용도 | 솔버 | 입력 |
|---|---|---|
| 간이 검토 (오리가미 접힘) | 바-힌지 자체 솔버 | OBJ 면(`f`) + `hinge_*` 선 |
| 바·쉘 FEM | CalculiX | OBJ 선(`l`)·면(`f`) |
| 솔리드 FEM | TensorMesh (CalculiX로도 가능) | STL (닫힌 표면) |

단위는 mm · N · tonne · s · MPa 입니다.

## 설치 (WSL2 Ubuntu, 회사 PC)

Windows 회사 PC 에서는 WSL2 Ubuntu 안에서 돌리는 것을 기본으로 합니다. 자세한 절차(프록시, 사내 인증서, NVIDIA GPU, 메모리 설정)는 [docs/WSL.md](docs/WSL.md) 에 있습니다.

```bash
git clone -b wip/shell-solver https://github.com/MunkyunLEE/FEM-LLM-web.git ~/FEM-LLM-web
cd ~/FEM-LLM-web
./scripts/setup_wsl.sh --apt
./scripts/run_wsl.sh
```

## 설치 (macOS, Apple Silicon)

```bash
git clone https://github.com/MunkyunLEE/FEM-LLM-web.git
cd FEM-LLM-web
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-solid.txt
```

`requirements-solid.txt`(PyTorch, TensorMesh, ipctk)는 솔리드 해석과 자체 쉘 솔버에 필요합니다. Python 3.10 이상이 필요합니다.

CalculiX:

```bash
brew install costerwi/homebrew-calculix/calculix-ccx
```

설치된 실행 파일 이름이 `ccx` 가 아니면 (`ccx_2.22` 등) 자동으로 찾습니다. 못 찾으면 `export FEMWEB_CCX=/경로/ccx_2.22` 로 지정합니다.

LLM 은 설치하지 않습니다. 기본은 규칙 기반 해석기만 쓰고, 화면 LLM 칸에 OpenAI 호환 엔드포인트(사내 게이트웨이, OpenAI, Gemini 등)와 모델 이름을 넣으면 그 LLM 을 함께 씁니다.

## 실행

```bash
python -m femweb
```

브라우저에서 `http://127.0.0.1:8765` 가 열립니다. 서버가 화면까지 함께 제공하므로 별도 웹 호스팅은 필요 없습니다.

환경변수:
- LLM: `FEMWEB_LLM_URL`(기본 비어 있음 = LLM 미사용), `FEMWEB_LLM_MODEL`, `FEMWEB_LLM_KEY`, `FEMWEB_LLM_MODE`(`rule_first` · `auto` · `llm` · `rule`, URL 이 없으면 `rule`), `FEMWEB_LLM_NOTHINK=1`(문장 끝에 `/no_think` 를 붙임, Qwen3 계열용)
- 네트워크: LLM 호출은 `HTTPS_PROXY`·`NO_PROXY` 를 따르고, 사내 인증서는 `FEMWEB_CA_BUNDLE`(또는 `REQUESTS_CA_BUNDLE`, `SSL_CERT_FILE`)로 지정합니다
- 계산: `FEMWEB_CCX`, `FEMWEB_DEVICE`(`cpu` · `cuda` · `mps` · `auto`), `FEMWEB_HESS`, `FEMWEB_THREADS`

LLM 설정은 화면에서도 바꿀 수 있습니다.

## 지오메트리 규칙

**OBJ (보·쉘)** — Rhino에서 메쉬와 선을 OBJ로 내보냅니다.

- `l` 선 = 보 요소, `f` 면(삼각형·사각형) = 쉘 요소
- `g 이름` 그룹은 선택 대상과 단면 지정에 쓰입니다 (`그룹 col_base 를 고정해줘`)
- 접힘선은 그룹 이름이 `hinge` 로 시작하는 `l` 선으로, 쉘 엣지 위에 그립니다
- 같은 위치의 정점은 자동으로 합쳐집니다
- `요소 분할수` k 를 주면 각 엣지를 k 등분합니다 (선은 k개, 사각형은 k×k개). 하중 합과 힌지 강성은 분할수와 무관하게 유지됩니다. 곡면은 직선 분할이므로 원래 메쉬를 충분히 잘게 내보내야 합니다

**STL (솔리드)** — 닫힌(watertight) 표면이어야 합니다. 서버가 Gmsh로 사면체 메쉬를 만들고, 평면·곡면 조각을 `face_1`, `face_2` … 그룹으로 등록합니다.

## 문장 처리 방식 (규칙 우선)

기본 방식은 `규칙 우선` 입니다. 문장을 먼저 내장 규칙 해석기(`femweb/rules.py`)가 읽고, 남는 말 없이 전부 이해했을 때만 즉시 적용합니다. 이해하지 못한 말이 남으면 그 문장만 LLM으로 넘기고, LLM이 없으면 이해한 부분만 적용한 뒤 무엇을 못 알아들었는지 알려줍니다. 방향이나 위치가 빠진 문장은 LLM을 부르지 않고 바로 되묻습니다.

규칙이 다루는 범위: 고정·핀·롤러·대칭·자유도별 구속, 강제 변위·회전, 집중·압축·인장 하중, 선하중(N/mm), 압력, 모멘트, 자중, 재료 프리셋과 물성, 두께·보 단면, 힌지, 해석 종류·증분·모드, 분할수, 솔버, 그래프, 수정·삭제·되돌리기·해석 실행. 위치는 `x 최소/최대`, `왼쪽/오른쪽/위/아래/앞/뒤`, `끝단/고정단/반대쪽/양단/중앙`, `테두리`, `네 모서리`, `x=100`, `x가 10에서 50 사이`, 좌표, 그룹 이름으로 가리킵니다. 단위는 N·kN·kgf·톤, mm·cm·m, MPa·kPa·bar, N·m, 도·rad 를 읽습니다.

LLM 방식 값: `rule_first`(기본) · `auto`(LLM 우선) · `llm` · `rule`.

## 쉘 사이 공유 엣지와 핀 조인트

Rhino에서 따로 만든 쉘의 엣지가 맞닿아 있으면 불러올 때 절점이 합쳐져 강접이 됩니다. 이 이음을 힌지로 바꾸려면:

```
쉘 사이 공유 엣지를 핀 조인트로 처리해줘     (그룹 경계 + 꺾인 엣지를 힌지로, 회전 자유)
그룹 경계를 힌지로 처리해줘
꺾인 엣지를 힌지로, 각도 10도 이상
힌지 강성 0.05                              (N·mm/rad/mm)
힌지 해제
```

왼쪽 `쉘 공유 엣지 힌지` 선택과 `핀 조인트` 체크로도 같은 설정을 합니다. CalculiX에서는 접힘선 절점을 패널별로 분리해 병진 자유도만 묶고(핀), 강성이 있으면 접힘선을 가로지르는 작은 보로 회전 스프링을 넣습니다. 바-힌지에서는 접힘 스프링 강성으로 들어갑니다.

### 스펙 수정 지시 (LLM 출력 형식)

LLM은 `.inp` 를 쓰지 않고 아래 형태의 수정 지시만 냅니다. 서버가 검증한 뒤 솔버 입력으로 바꿉니다.

```json
{"ops": [
  {"op": "add_bc", "type": "fixed", "select": {"plane": {"axis": "x", "at": "min"}}},
  {"op": "add_load", "type": "force", "vector": [0, 0, -1000], "select": {"plane": {"axis": "x", "at": "max"}}},
  {"op": "add_plot", "title": "에너지", "x": {"quantity": "time"}, "series": [{"quantity": "energy.total"}]}
], "reply": "…"}
```

선택(`select`)은 `group`, `plane`, `box`, `nearest`, `nodes`, `all` 과 `and` / `or` 조합입니다. 힘은 선택 영역 전체에 대한 합이며 면·엣지·절점 순으로 분배합니다.

## 구현 범위와 한계

- **CalculiX 어댑터**: B31 보, S8R/S6 쉘(중간 절점 자동 생성), C3D10 솔리드. 정적(선형·기하비선형·소성), 좌굴, 모달. 결과는 CalculiX가 펼친 3D 메쉬 그대로 표시합니다
- **바-힌지**: N5B8 위상(사각 패널 중심 절점 + 바 8개). 바 면적과 패널 굽힘 강성은 Filipov 등(2017)의 N4B5 식을 그대로 적용한 근사입니다. 하중·변위 제어 Newton, 호장법, 1차 좌굴 모드 초기 결함, 음의 고유치 수로 분기점을 감지해 좌굴 가지로 전환. 접촉은 없습니다
- **힌지 강성**: 길이당 κ (N·mm/rad/mm). 비워 두면 κ = 비율 × D / L (D 판 휨강성, L 패널 평균 변 길이)
- **CalculiX의 접힘선**: 절점 분리 + 병진 구속(핀) + 회전 스프링 보. 평평한 2패널 시험에서 회전 스프링 보 이론과 6% 이내, 핀 조인트 3패널 예제는 힌지 보 이론과 일치, 핀 미우라는 바-힌지와 최대 변위 2% 이내입니다. 강성이 있는 미우라에서는 반력이 바-힌지의 약 0.8배이고 분할수 2·4·8에서 거의 같습니다(이전 띠 방식은 4~13배). 남은 차이의 원인은 아직 찾지 못했습니다. 이전 띠 방식은 `{"op":"set_hinge","method":"strip"}` 으로 쓸 수 있습니다
- **TensorMesh 어댑터**: 2차 사면체 선형 정적, Neo-Hookean 기하비선형(Newton-CG). 좌굴·모달·소성·열·유체는 아직 연결하지 않았습니다
- **LLM**: 실제 LLM 으로는 시험하지 못했습니다. 연결 흐름(프록시 터널 포함)은 모의 서버로 시험했습니다
- 시험은 Linux에서 했습니다. macOS 실기 확인이 필요합니다

## 좌굴 이후 거동

- **변위 제어**: 스텝의 제어 방식을 변위 제어로 바꾸거나 "변위제어 5 mm"라고 입력합니다. 첫 번째 힘·압력 하중이 기준이 되고, 하중-변위 곡선이 자동으로 추가됩니다. 방법은 하중 분포 유지(기본)와 강체 압판 두 가지입니다
- **초기 결함**: "초기결함 0.1". 1차 좌굴 모드를 지정 크기로 형상에 더합니다. 세 솔버 모두 적용됩니다 (TensorMesh는 모드 계산에 CalculiX 필요)
- **분기 전환**: 바-힌지 전용, 기본 켜짐. "분기 전환 꺼줘"로 주 경로만 따라가게 할 수 있습니다
- **한계**: CalculiX·TensorMesh는 호장법이 없어 스냅백은 풀지 못합니다. 분기 전환은 쉘·솔리드 솔버에는 없으므로 초기 결함을 쓰세요

## 접촉

- **강체 구**: "반지름 20 구를 아래로 3 mm 눌러, 마찰 0.2". 중심을 생략하면 모델 중앙에서 이동 반대쪽 면에 닿도록 놓습니다
- **강체 평면**: "바닥에 강체 평면 접촉", "강체 평면으로 위에서 2 mm 눌러"
- **변형체끼리**: "body_2 와 body_1 사이 접촉, 마찰 0.3". 그룹 이름 두 개를 쓰면 됩니다. STL의 떨어진 덩어리는 body_1, body_2 … 로 자동 구분됩니다
- **수정·삭제**: "마찰계수 0.1", "ct1 삭제", "접촉 삭제". 왼쪽 접촉 목록에서도 마찰계수와 이동량을 바꿀 수 있습니다
- **솔버**: CalculiX(쉘·솔리드), TensorMesh(솔리드). 페널티 방식이고 기본 강성은 10×E MPa/mm (`stiffness` 로 변경)
- **한계**: 강체는 이동량 지정만 됩니다(하중 지정 불가, 회전 불가). 자기 접촉은 자체 쉘 솔버에만 있습니다. 보 요소 접촉, 바-힌지 접촉은 없습니다. TensorMesh 접촉은 메쉬가 커지면 느립니다
- 예제 7a(패널에 강체 구 압입), 7b(블록 두 개 접촉)

## 자체 쉘 솔버 (대변형, 자기 접촉, 감쇠)

CalculiX 에 맡기지 않고 직접 만든 쉘 솔버입니다. "자체 쉘 솔버로" 라고 쓰거나 솔버 목록에서 고릅니다. OBJ 패널 모델의 정적 해석만 지원합니다.

- **요소**: 면이 모두 사각형이면 4절점 사각형 요소, 아니면 3절점 삼각형 요소를 씁니다("쿼드 요소로", "삼각형 요소로" 또는 화면의 쉘 요소 칸으로 바꿉니다). 기하 비선형은 항상 켜져 있고, 뉴턴 음해법으로 풉니다
  - 사각형: 절점마다 병진 3 + 회전 3 자유도. 전단은 MITC4 가정 변형률, 면내 전단은 중심 1점 적분, 2x2 적분. 회전은 증분 회전 벡터로 갱신하고, 꺾인 모서리(20도 이상)는 요소별 법선을 씁니다. 회전 구속과 모멘트 하중을 지원합니다
  - 삼각형: 막은 상수 변형률, 휨은 모서리마다 회전 자유도 하나를 두는 방식(Morley 계열). 사각형 면이 섞여 있으면 삼각형 둘로 나눕니다
- **접촉**: IPC 장벽법(ipctk 라이브러리). "자기 접촉 추가 마찰 0.2" 로 모든 면끼리의 접촉을 켭니다. 강체 구·평면, 그룹 쌍 접촉도 같은 방식으로 풉니다. 면 사이 최소 간격은 두께이고, 연속 충돌 검사로 한 증분에 면을 뚫고 지나가지 못하게 막습니다. 페널티 계수를 맞출 필요가 없습니다
- **감쇠**: "레일리 감쇠 2%", "질량 비례 감쇠 3%", "강성 비례 감쇠 1%", "감쇠 없이". 1·2차 고유진동수에서 그 감쇠비가 되도록 α, β 를 자동 계산하고 후방 오일러 음해법으로 시간 적분합니다. 스텝 시간을 0으로 두면 1차 주기의 100배를 씁니다. 결과 요약의 "감쇠 소산 / 변형 에너지" 가 작아야 준정적 결과로 볼 수 있습니다
- **변위 제어**: 강체 압판 방식만 됩니다. 초기 결함은 자체 선형 좌굴 모드로 넣습니다
- **증가 곡선**: "부드럽게" 라고 쓰면 하중·지정 변위를 S자 곡선으로 올립니다
- **탄소성**: 재료에 항복(과 경화 계수)이나 소성 곡선을 주면 켜집니다. "항복 240 경화 1000", "소성 곡선 240@0, 275@0.02, 300@0.06, 330@0.2" (진응력@소성변형률). J2 등방 경화, 평면응력 반환 사상, 두께 방향 심프슨 5점, 일관 접선. 곡선은 CalculiX 에도 그대로 전달됩니다. 소성 변형률은 그린 변형률 기준의 소변형률 식이라 변형률이 수십 %인 접힘부는 근사입니다
- **없는 것**: 호장법, 좌굴·모달 스텝, 보 요소, 핀 조인트 힌지, 모멘트 하중, 여러 재료, 이동 경화, 변형률 속도 의존성
- **검증**: 외팔보 대변형(elastica) 처짐 0.3019 L (기준 0.3017 L), 단순지지 정사각 판 처짐 0.5% 이내, 사각관 선형 좌굴 하중 24.44 kN (CalculiX S8R 24.43 kN, 벽당 16분할. 벽당 8분할이면 5% 낮음)
- **사각형 요소 검증**: 외팔보 대변형 처짐 0.3016 L, 0.4935 L (elastica 0.3017, 0.4935), 정사각 판 8분할에서 1% 이내, 면내 휨 0.6% 이내(잠김 없음), 사각관 좌굴 하중 벽당 8분할 25.01 kN, 16분할 24.57 kN (CalculiX 24.43), 소성 단축 인장은 해석해와 일치, 소성 외팔 판 48.9 N (삼각형 47.4 N)
- **탄소성 검증**: 단축 인장은 이선형 해석해와 일치(응력 0.1% 이내, 등가 소성 변형률 1e-6 이내). 외팔 판(50×10×2, 항복 200, 경화 1000) 끝단 8 mm 처짐 반력 47.4 N, CalculiX S8R 55.6 N. CalculiX 쉘은 두께 방향 적분점이 2개라 소성 모멘트를 약 15% 크게 잡으며, 자체 솔버를 같은 2점 적분으로 돌리면 54.3 N 입니다
- **반력·접촉력 출력**: 구속마다 반력 합(`reaction.bc1.z` 등, 요약에 끝값), 접촉 수직력 합과 마찰력 합(`contact.normal`, `contact.friction`, 자기 접촉 포함)이 이력으로 나옵니다. "접촉력 그래프", "bc1 반력 z 그래프" 로 그립니다. 컨투어 필드로 절점 반력 RF, 절점 접촉력 CFORCE, 접촉 압력 CPRESS(절점 접촉 수직력 ÷ 절점 담당 면적)를 고를 수 있습니다. 자체 쉘 솔버에만 있습니다
- **강체 누름판 압축**: 위 끝을 구속하지 않고 "위에서 강체 평면을 아래로 60 mm 눌러, 마찰 0.2" 처럼 강체 평면 접촉으로 누를 수 있습니다. 하중이 없어도 초기 결함은 판이 처음 닿는 끝단 절점에 판 방향 하중을 건 선형 좌굴 모드로 넣습니다. 판에 닿아 있는 절점은 판 이동량을 지정 변위로 두고 관 전체를 한 번 풀어서 다음 증분의 시작점으로 씁니다
- **에너지 출력**: `energy.strain`(탄성 변형), `energy.plastic`(소성 소산), `energy.damping`(감쇠 소산), `energy.friction`(마찰 소산), `energy.contact`(접촉 장벽), `energy.kinetic`, 그 합인 `energy.total` 과 강체 이동·지정 변위·하중이 한 일 `energy.external` 이 이력으로 나옵니다. 요약의 "에너지 균형 오차" 로 해석의 건전성을 봅니다
- **자기 접촉과 요소 크기**: 처음 형상에서 서로 (두께 + 장벽 범위 + 요소 변 길이 x 2) 안쪽에 있는 절점 쌍은 자기 접촉 판정에서 뺍니다. 요소가 두께의 2~3배로 작으면 꺾인 모서리나 굴곡부의 이웃 요소가 처음부터 최소 간격 안에 들어와 가짜 접촉력이 생기기 때문입니다. 마찰은 미끄럼 0.1 x 두께까지 부드럽게 커지도록 정규화합니다
- **계산 속도**: 뉴턴 반복은 수렴이 빠른 동안 이전 강성 행렬의 LU 분해를 다시 쓰고(수정 뉴턴), 느려지거나 선 탐색·충돌 제한이 걸리면 새로 계산합니다. 선형 풀이는 대칭 정렬(MMD) SuperLU 입니다. 환경 변수로 더 빠르게 할 수 있습니다
  - `FEMWEB_THREADS`: PyTorch 스레드 수 (기본 auto = 코어 수의 절반, 최대 4)
  - `FEMWEB_HESS=float32`: 요소 강성 행렬만 단정밀도로 계산 (약 1.5배). 잔차는 배정밀도라 수렴한 해의 정확도는 같습니다
  - `FEMWEB_DEVICE=cuda`(NVIDIA, WSL2 포함) 또는 `mps`(Apple GPU), `auto`(있는 GPU 자동 선택): 요소 강성 행렬을 GPU 에서 계산합니다. CUDA 는 배정밀도, MPS 는 배정밀도가 없어 단정밀도가 기본입니다. 선형 방정식 풀이는 CPU 입니다
  - `scikit-sparse` 가 설치되어 있으면 CHOLMOD 촐레스키 분해를 먼저 시도합니다 (macOS: `brew install suite-sparse` 후 `pip install scikit-sparse`). 양정치가 아니면 SuperLU 로 돌아갑니다. 끄려면 `FEMWEB_CHOLMOD=0`
- **계산 장치 선택**: 해석 설정의 "계산 장치(자동·CPU·GPU)", "강성 정밀도(자동·배정밀도·단정밀도)", "CPU 스레드" 칸이나 "GPU로 계산해줘", "단정밀도로", "스레드 8개" 같은 문장으로 해석마다 고릅니다. 환경 변수(`FEMWEB_DEVICE` 등)보다 우선합니다. 쓸 수 없는 GPU 를 고르면 CPU 로 풀고 결과 요약에 알립니다. 오른쪽 위 GPU 표시등에 잡힌 GPU 이름이 나옵니다
- **진행 표시**: 해석 중에는 화면 아래 알림줄에 진행률, 증분 번호, 강체 이동량(또는 제어 변위), 경과 시간, 남은 시간 추정이 1초마다 갱신됩니다(`GET /api/progress`). 자체 쉘 솔버만 증분 정보가 있고, 다른 솔버는 경과 시간만 나옵니다
- **해석 재개**: `solve(model, spec, checkpoint="ck.pkl", every=300)` 으로 몇 초마다 솔버 상태(변형, 방향 벡터, 소성 변형률, 감쇠 속도, 이력, 프레임)를 저장하고, 끊기면 `resume="ck.pkl"` 로 그 지점부터 이어서 풉니다. 이어 푼 결과는 끊김 없이 푼 결과와 같습니다(시험으로 확인)
- **결과 화면**: 쉘을 두께만큼 띄운 양면과 옆면으로 그리고("쉘 두께" 체크), 메쉬선은 원래 사각형 모서리만 표시합니다. 결과 막대의 PNG·GIF·영상 버튼으로 지금 화면이나 전체 프레임을 저장합니다(GIF 는 Pillow 필요, 영상은 브라우저에 따라 mp4 또는 webm)
