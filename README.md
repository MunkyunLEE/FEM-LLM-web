# FEM-LLM-web

지오메트리를 웹에 올리고, 문장으로 경계조건·하중을 지시한 뒤, 로컬 솔버로 해석하고 결과를 3D로 확인하는 개인용 FEM 도구입니다.

```
지오메트리 업로드 (OBJ / STL)
  → 문장 지시 → LLM이 스펙 수정 지시(JSON)를 생성 → 검증 → 화면에 구속·하중 표시
  → 해석 실행 (로컬 솔버)
  → 변형·컨투어·그래프 확인 (그래프도 문장으로 요청)
```

| 용도 | 솔버 | 입력 |
|---|---|---|
| 간이 검토 (오리가미 접힘) | 바-힌지 자체 솔버 | OBJ 면(`f`) + `hinge_*` 선 |
| 바·쉘 FEM | CalculiX | OBJ 선(`l`)·면(`f`) |
| 솔리드 FEM | TensorMesh (CalculiX로도 가능) | STL (닫힌 표면) |

단위는 mm · N · tonne · s · MPa 입니다.

## 설치 (macOS, Apple Silicon 기준)

```bash
git clone https://github.com/MunkyunLEE/FEM-LLM-web.git
cd FEM-LLM-web
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-solid.txt
```

`requirements-solid.txt`(PyTorch, TensorMesh)는 솔리드 해석에만 필요합니다. Python 3.10 이상이 필요합니다.

CalculiX:

```bash
brew install costerwi/homebrew-calculix/calculix-ccx
```

설치된 실행 파일 이름이 `ccx` 가 아니면 (`ccx_2.22` 등) 자동으로 찾습니다. 못 찾으면 `export FEMWEB_CCX=/경로/ccx_2.22` 로 지정합니다.

Ollama (로컬 LLM, 선택):

```bash
brew install ollama        # 또는 https://ollama.com/download 의 앱 설치
ollama serve               # 앱으로 설치했다면 생략
ollama pull qwen3:8b
```

LLM이 없어도 규칙 기반 해석기가 대신 동작하므로 화면 흐름은 그대로 쓸 수 있습니다.

## 실행

```bash
python -m femweb
```

브라우저에서 `http://127.0.0.1:8765` 가 열립니다. 서버가 화면까지 함께 제공하므로 별도 웹 호스팅은 필요 없습니다.

환경변수: `FEMWEB_LLM_URL` (기본 `http://localhost:11434/v1`), `FEMWEB_LLM_MODEL` (기본 `qwen3:8b`), `FEMWEB_LLM_KEY`, `FEMWEB_LLM_MODE` (`auto` · `llm` · `rule`), `FEMWEB_CCX`, `FEMWEB_LLM_THINK` (1 이면 Qwen3 의 생각 단계를 켬, 기본은 끔). 더 정확한 답이 필요하면 `qwen3:14b` 를 쓰세요 (느립니다). LLM 설정은 화면 오른쪽 위에서도 바꿀 수 있고, OpenAI 호환 엔드포인트면 어떤 것이든 연결됩니다.

## 지오메트리 규칙

**OBJ (보·쉘)** — Rhino에서 메쉬와 선을 OBJ로 내보냅니다.

- `l` 선 = 보 요소, `f` 면(삼각형·사각형) = 쉘 요소
- `g 이름` 그룹은 선택 대상과 단면 지정에 쓰입니다 (`그룹 col_base 를 고정해줘`)
- 접힘선은 그룹 이름이 `hinge` 로 시작하는 `l` 선으로, 쉘 엣지 위에 그립니다
- 같은 위치의 정점은 자동으로 합쳐집니다
- `요소 분할수` k 를 주면 각 엣지를 k 등분합니다 (선은 k개, 사각형은 k×k개). 하중 합과 힌지 강성은 분할수와 무관하게 유지됩니다. 곡면은 직선 분할이므로 원래 메쉬를 충분히 잘게 내보내야 합니다

**STL (솔리드)** — 닫힌(watertight) 표면이어야 합니다. 서버가 Gmsh로 사면체 메쉬를 만들고, 평면·곡면 조각을 `face_1`, `face_2` … 그룹으로 등록합니다.

## 문장 처리 방식 (규칙 우선)

기본 방식은 `규칙 우선` 입니다. 문장을 먼저 내장 규칙 해석기(`femweb/rules.py`)가 읽고, 남는 말 없이 전부 이해했을 때만 즉시 적용합니다. 이해하지 못한 말이 남으면 그 문장만 LLM으로 넘기고, LLM이 없으면 이해한 부분만 적용한 뒤 무엇을 못 알아들었는지 알려줍니다. 방향이나 위치가 빠진 문장은 LLM을 부르지 않고 바로 되묻습니다.

규칙이 다루는 범위: 고정·핀·롤러·대칭·자유도별 구속, 강제 변위·회전, 집중·압축·인장 하중, 선하중(N/mm), 압력, 모멘트, 자중, 재료 프리셋과 물성, 두께·보 단면, 힌지, 해석 종류·증분·모드, 분할수, 솔버, 그래프, 수정·삭제·되돌리기·해석 실행. 위치는 `x 최소/최대`, `왼쪽/오른쪽/위/아래/앞/뒤`, `끝단/고정단/반대쪽/양단/중앙`, `테두리`, `네 모서리`, `x=100`, `x가 10에서 50 사이`, 좌표, 그룹 이름으로 가리킵니다. 단위는 N·kN·kgf·톤, mm·cm·m, MPa·kPa·bar, N·m, 도·rad 를 읽습니다.

LLM 방식 값: `rule_first`(기본) · `auto`(LLM 우선) · `llm` · `rule`.

## 쉘 사이 공유 엣지와 핀 조인트

Rhino에서 따로 만든 쉘의 엣지가 맞닿아 있으면 불러올 때 절점이 합쳐져 강접이 됩니다. 이 이음을 힌지로 바꾸려면:

```
쉘 사이 공유 엣지를 핀 조인트로 처리해줘     (그룹 경계 + 꺾인 엣지를 힌지로, 회전 자유)
그룹 경계를 힌지로 처리해줘
꺾인 엣지를 힌지로, 각도 10도 이상
힌지 강성 0.05                              (N·mm/rad/mm)
힌지 해제
```

왼쪽 `쉘 공유 엣지 힌지` 선택과 `핀 조인트` 체크로도 같은 설정을 합니다. CalculiX에서는 접힘선 절점을 패널별로 분리해 병진 자유도만 묶고(핀), 강성이 있으면 접힘선을 가로지르는 작은 보로 회전 스프링을 넣습니다. 바-힌지에서는 접힘 스프링 강성으로 들어갑니다.

## 지시 예시

```
x 최소인 끝을 완전 고정해줘
x 최대 끝단에 z 방향으로 -1000 N 하중 줘
네 변 모두 z 방향만 구속해줘
상단 면에 0.5 MPa 압력
x 최대 변을 x 방향으로 -5 mm 밀어줘
좌굴 해석으로 바꾸고 모드 4개
비선형 해석으로 증분 20
시간-총에너지 그래프 그려줘
절점 (100, 0, 0) 의 z 방향 변위 그래프 그려줘
bc1 삭제해줘
```

화면에서 절점을 클릭하면 좌표가 표시되고 `지시문에 넣기` 로 문장에 넣을 수 있습니다. 구속·하중 목록에서 값을 직접 고치거나 지울 수도 있으며, 문장 지시와 같은 스펙을 수정합니다.

### 스펙 수정 지시 (LLM 출력 형식)

LLM은 `.inp` 를 쓰지 않고 아래 형태의 수정 지시만 냅니다. 서버가 검증한 뒤 솔버 입력으로 바꿉니다.

```json
{"ops": [
  {"op": "add_bc", "type": "fixed", "select": {"plane": {"axis": "x", "at": "min"}}},
  {"op": "add_load", "type": "force", "vector": [0, 0, -1000], "select": {"plane": {"axis": "x", "at": "max"}}},
  {"op": "add_plot", "title": "에너지", "x": {"quantity": "time"}, "series": [{"quantity": "energy.total"}]}
], "reply": "…"}
```

선택(`select`)은 `group`, `plane`, `box`, `nearest`, `nodes`, `all` 과 `and` / `or` 조합입니다. 힘은 선택 영역 전체에 대한 합이며 면·엣지·절점 순으로 분배합니다.

## 원리 문서

화면 오른쪽 위 `Theory` 버튼 (`/theory.html`) 에 로드맵, 유한요소 수식, 바-힌지 모델, LLM 연결 방식이 정리되어 있습니다.

## 구현 범위와 한계

- **CalculiX 어댑터**: B31 보, S8R/S6 쉘(중간 절점 자동 생성), C3D10 솔리드. 정적(선형·기하비선형·소성), 좌굴, 모달. 결과는 CalculiX가 펼친 3D 메쉬 그대로 표시합니다
- **바-힌지**: N5B8 위상(사각 패널 중심 절점 + 바 8개). 바 면적과 패널 굽힘 강성은 Filipov 등(2017)의 N4B5 식을 그대로 적용한 근사입니다. 하중·변위 제어 Newton, 호장법, 1차 좌굴 모드 초기 결함, 음의 고유치 수로 분기점을 감지해 좌굴 가지로 전환. 접촉은 없습니다
- **힌지 강성**: 길이당 κ (N·mm/rad/mm). 비워 두면 κ = 비율 × D / L (D 판 휨강성, L 패널 평균 변 길이)
- **CalculiX의 접힘선**: 절점 분리 + 병진 구속(핀) + 회전 스프링 보. 평평한 2패널 시험에서 회전 스프링 보 이론과 6% 이내, 핀 조인트 3패널 예제는 힌지 보 이론과 일치, 핀 미우라는 바-힌지와 최대 변위 2% 이내입니다. 강성이 있는 미우라에서는 반력이 바-힌지의 약 0.8배이고 분할수 2·4·8에서 거의 같습니다(이전 띠 방식은 4~13배). 남은 차이의 원인은 아직 찾지 못했습니다. 이전 띠 방식은 `{"op":"set_hinge","method":"strip"}` 으로 쓸 수 있습니다
- **TensorMesh 어댑터**: 2차 사면체 선형 정적, Neo-Hookean 기하비선형(Newton-CG). 좌굴·모달·소성·열·유체는 아직 연결하지 않았습니다
- **LLM**: Ollama 실모델로는 아직 시험하지 못했습니다. 연결 흐름은 모의 서버로 시험했습니다
- 시험은 Linux에서 했습니다. macOS 실기 확인이 필요합니다

## 좌굴 이후 거동

- **변위 제어**: 스텝의 제어 방식을 변위 제어로 바꾸거나 "변위제어 5 mm"라고 입력합니다. 첫 번째 힘·압력 하중이 기준이 되고, 하중-변위 곡선이 자동으로 추가됩니다. 방법은 하중 분포 유지(기본)와 강체 압판 두 가지입니다
- **초기 결함**: "초기결함 0.1". 1차 좌굴 모드를 지정 크기로 형상에 더합니다. 세 솔버 모두 적용됩니다 (TensorMesh는 모드 계산에 CalculiX 필요)
- **분기 전환**: 바-힌지 전용, 기본 켜짐. "분기 전환 꺼줘"로 주 경로만 따라가게 할 수 있습니다
- **한계**: CalculiX·TensorMesh는 호장법이 없어 스냅백은 풀지 못합니다. 분기 전환은 쉘·솔리드 솔버에는 없으므로 초기 결함을 쓰세요
