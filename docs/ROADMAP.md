# FEM-LLM-web 로드맵 (2026-11-15)

## 목표
- 웹(3D 뷰어, 회전·클릭 확인)에서 LLM이 경계조건·하중을 JSON 스펙으로 생성하고, 구속·하중이 화면에 표시됨
- 솔버는 로컬 실행, 검증은 Abaqus로 별도 수행
- 테스트는 Mac(M1, 32GB) 기준, 골격 완성 후 Windows/Linux 솔버 패키지를 다운로드로 제공, 웹은 GitHub 경유

## 솔버 구성
- 간이 검토용: 바-힌지 모델 (N5B8 기반, 강체접힘·경로추적·다안정 등 비선형 포함), 자체 솔버
- FEM (바·쉘 요소): CalculiX (재료·기하 비선형, 접촉 일부)
- FEM (솔리드, 구조·열·유체): TensorMesh (후순위, 어댑터 슬롯 먼저 확보)
- 제외: JAX-FEM (GPL-3.0, TensorMesh와 영역 중복)

## 구조
- 공통 모델 IR(JSON): 절점, 요소(트러스/보/쉘/솔리드/바-힌지), 재료, 단면, BC, 하중, 스텝, hinge 엔티티
- 입력은 OBJ 유지 (보=l, 쉘=f, 그룹별 단면·재료)
- 어댑터: 기존 JS 솔버 / CalculiX / 바-힌지 / TensorMesh / Abaqus .inp 내보내기
- LLM: JSON 스펙만 출력, 스키마 검증 후 변환기가 .inp 생성, 지오메트리 질의 도구 제공, 실행 전 화면 확인
- LLM 호출부는 OpenAI 호환 엔드포인트로 추상화 (기본 로컬 모델, 필요 시 Claude API)

## 힌지 표현
- Abaqus 현행: 접힘선의 동일 좌표 절점 쌍마다 커넥터 (병진 1e6/n, 회전 0.001/n), 엣지당 상수, rest angle은 초기 형상
- 변경 결정: 강성은 길이당 값 κ로 정의하고 요소 분할수에 자동 반영
  - 절점 쌍 강성 = κ × 해당 쌍의 분담 길이 (양 끝 절점은 절반)
  - 바-힌지: 힌지 강성 = κ × 엣지 길이
  - CalculiX: 쉘 띠(strip), 두께 t = (12(1-nu^2)·κ·w / E)^(1/3), Abaqus 커넥터 결과와 비교해 보정
- CalculiX 스프링은 병진 자유도만 지원하므로 커넥터형 회전스프링 불가, 병진 구속은 *EQUATION 대체 검토 (미검증)

## 단계
1. 모델 IR + 3D 뷰어 + BC·하중 시각화
2. LLM → JSON 스펙 → 미리보기 → 승인
3. CalculiX 어댑터 (Homebrew 설치 검증 포함)
4. 바-힌지 솔버
5. TensorMesh 어댑터, Win/Linux 솔버 패키지

## 열린 항목
- rest angle: 초기 형상 기준으로 충분한지 (N5B8 별도 기준각 필요 여부)
- 쉘 띠 병진 구속 방식(*EQUATION 등) 검증
- GitHub Pages에서 localhost 솔버 호출 (Safari 제약 가능성), 로컬 서버가 UI까지 서빙하는 방식을 기본으로 검토
- 로컬 LLM 모델 선정 (32GB 기준 14B~27B급 4bit 후보, 스펙 JSON 정확도로 평가)
